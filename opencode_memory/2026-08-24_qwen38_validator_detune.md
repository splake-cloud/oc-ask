## Operational rules learned
- **Global lane**: edit `opencode.jsonc` → restart opencode server (config cache, Gotcha 3).
- **Staged lane**: edit registry → RESTAGE (`OC_SEAT_PROFILE=validate38 python3
  scripts/oc_seat_stage.py rig/seats/sqlmesh_builder.yaml`) → restart (or attach after
  restart; the cache is per-dir and fills on first access). A restart alone does NOT update
  a staged seat — its values are baked into the workdir at stage time.
- **One-time re-prefill cost**: effort is injected at the START of the rendered prompt, so
  the first validator call after an effort change pays a full cold prefill (~50 s vs ~28 s
  at ~95k). Set effort seat-wide and stay on it — ping-ponging evicts both prefix variants.
- Dry-run pattern: `--suffix skunk` stages to a throwaway `/var/tmp/oc_<name>_skunk` without
  touching the live seat — use it to prove generator changes before a live restage.
