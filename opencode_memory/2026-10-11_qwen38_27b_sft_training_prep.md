## Bug found + fixed (delegated EDIT to qwen-coder, verified)
`tmpl_len` used `ids = out["input_ids"] if isinstance(out, dict) else out`. In **transformers 5.19.0** `apply_chat_template(tokenize=True)` returns a `BatchEncoding` that is **NOT a `dict` subclass** (verified `isinstance(out, dict)` is False) → guard always False → `ids` = whole BatchEncoding → `len()` = 2 (its two keys). Every record reported a degenerate length of 2. Fix: index `out["input_ids"]` directly (+ defensive batched-unwrap). Re-run EXIT=0, realistic distribution (12-message record = 4363, matches hand-verified count).
